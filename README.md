# 国际扫码点餐项目全套开源系统

源码地址：ym7k.com/20134/

面向海外餐厅、华人餐馆、跨境餐饮门店经营需求，这套国际扫码点餐全套开源系统围绕多语言点餐、菜品管理、下单支付、后厨出餐、门店运营打造完整业务流程，支持私有化部署，适合海外中餐厅、异国特色餐厅、连锁轻食店快速搭建本地化扫码点餐平台。

多语言切换是系统的基础核心能力，适配不同国家食客使用。顾客扫码打开点餐页面后，可以自由切换多种语言，菜品名称、菜品介绍、分类标签、下单提示、结算页面全部同步翻译展示，方便本地居民、游客、多国客人看懂菜单。商家后台同样支持多语言管理，能够录入菜品多版本名称与介绍，灵活适配门店所在地区的语言环境，消除语言沟通障碍。

菜品与菜单管理模块，满足门店日常上架维护需求。管理员可以新建菜品分类，比如主食、饮品、小吃、套餐等，上传菜品图片、设置规格选项，包含口味、辣度、分量等选择项。支持设置菜品状态，在售、售罄、暂停供应一键切换，还能配置套餐组合、加料加价规则。菜单可以按时段启用，设置早餐、午餐、晚餐、夜宵不同菜单，到点自动切换，适配餐厅不同时段经营。

顾客扫码点餐流程简洁流畅。食客扫描桌台二维码，无需下载小程序或 APP，直接在浏览器 H5 页面点餐，选择菜品、调整数量，添加备注，比如不要洋葱、少糖等特殊要求。提交订单后，订单实时推送至后厨端，后厨人员可以看到菜品明细、顾客备注、对应桌号，按顺序制作出餐。系统支持堂食、外带两种模式切换，满足到店就餐和打包带走不同场景。

多元化支付适配海外经营场景。系统可以配置多种主流支付方式，支持本地电子钱包、信用卡支付等渠道，商家可自主开启或关闭对应支付选项。订单提交后自动计算金额、税费、服务费，商家能够根据当地法规设置税率，结算明细清晰展示给顾客，支付完成后自动生成订单回执，顾客可保存小票凭证，减少收银人工核算压力。

订单、后厨与桌台管理相互联动。后台可视化展示全部桌台状态，空闲、用餐中、待结账一目了然。所有订单实时汇总，支持订单搜索，可按时间、桌号、支付状态筛选查看。后厨端可以标记菜品制作完成，服务员收到提醒后上菜，订单全程状态可追踪。支持合并账单、单独结账、退单操作，退单记录留存，方便门店对账管理。

营销与数据统计助力门店经营。商家可以设置满减优惠、折扣活动、优惠券，针对新客或者节假日推出促销方案。数据看板自动统计营业额、订单数量、热销菜品、客单价等经营指标，生成营业报表，支持导出数据用于财务对账。

后台权限管理保障门店分工协作。系统可创建店长、后厨、收银员等不同角色，分配对应的操作权限，后厨只查看出餐订单，收银员负责结账退款，避免越权操作。全套系统预留扩展接口，可后续对接外卖分发、会员储值、库存管理等功能。

整套系统不只是简单的扫码下单工具，集多语言菜单、扫码点单、后厨通知、多渠道支付、桌台管控、营业统计于一体。私有化部署让餐饮商家自主掌握订单和经营数据，不受第三方平台抽成约束，是海外各类餐饮门店低成本落地数字化点餐的实用方案。
